*hexa* is a foundational patterns that supports a data pipeline, stream oriented
programming style. It introduces the notions of data patterns expressed as shapes,
and projections to transform them.

*hexa* offers:
- The *regex* of data structures: define patterns you want to match
- Templates, where wou define the structures you want to fill and how you want it filled
- Projections and mappings, to transform from one shape to the other
